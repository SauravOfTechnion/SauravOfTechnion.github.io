# Original studio violin

Created specifically for Saurav Ramachandra Rao's portfolio in Blender 5.2.
Original mesh geometry, generated spruce and flamed-maple texture images,
and a separate bow assembly. No downloaded third-party model is used.

Editable source: `art/violin/violin.blend`
Reproducible authoring script: `scripts/build-violin.py`
Export: `public/models/violin.glb` (all textures embedded)

Proportional reference: Ruschil London workshop measurements,
https://www.ruschil.com/violin-measurements
355 mm body, 130 mm neck, 270 mm fingerboard. This is an artistic visualization,
not a manufacturing model or an exact reproduction of a historical instrument.
